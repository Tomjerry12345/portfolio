# Andri Alfiandi — Portfolio (Next.js)

Single-page portfolio built with Next.js 14 (App Router) and TypeScript. No UI library.

## Run locally
```bash
npm install
npm run dev     # http://localhost:3000
```

## Edit content
All text lives in `lib/data.ts`. Change projects, experience, skills and links there.
Styles are in `app/globals.css`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com choose "Add New Project", import the repository, and deploy. No settings need to change.
